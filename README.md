# Task Scheduler & Job Runner

A Python-based Task Scheduler and Job Runner with Cron job management, automatic task execution, SQLite database storage, and a Flask web dashboard for monitoring scheduled tasks and execution history.

## Features

- Cron job scheduling
- Automatic task execution
- Manual task execution
- Execution history monitoring
- SQLite database storage
- Flask web dashboard
- Scheduled task management

## Technologies Used

- Python
- Flask
- APScheduler
- SQLite
- HTML
- CSS
- JavaScript
